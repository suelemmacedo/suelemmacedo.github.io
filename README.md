# Portfólio | Suelem Macedo

Meu portfólio pessoal, desenvolvido com **HTML, CSS e JavaScript**, para apresentar minha trajetória profissional, habilidades técnicas e projetos na área de tecnologia.

🌐 **[Acesse meu portfólio](https://suelemmacedo.github.io/)**

---

## Sobre o projeto

O portfólio foi desenvolvido com uma interface moderna, responsiva e de tema escuro, priorizando uma navegação simples e uma apresentação objetiva das minhas experiências e projetos.

### Funcionalidades

- Layout responsivo para desktop, tablet e dispositivos móveis.
- Interface escura com elementos visuais tecnológicos.
- Apresentação profissional e trajetória na área de TI.
- Seção de projetos com links para repositórios.
- Tecnologias e ferramentas utilizadas.
- Navegação entre seções da página.
- Publicação automatizada pelo GitHub Pages.
